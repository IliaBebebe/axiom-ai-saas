Technical answers

Frequently asked technical questions

Clear architectural details without sales fluff.

How does Axiom enforce deterministic execution?
Axiom injects runtime validation schemas directly into the generation loop. If a downstream LLM produces tokens deviating from the target Pydantic or JSON schema specification, the orchestrator triggers an immediate micro retry with explicit differential error feedback within a strict 50ms window.
Can we deploy Axiom within our private AWS or GCP VPC?
Yes. Enterprise licenses include Helm charts and Terraform templates for automated Kubernetes deployment inside your private VPC. In this configuration, zero telemetry or model payloads ever leave your security perimeter.
What happens when an upstream provider experiences an outage?
Axiom maintains active health checks across providers. If an endpoint exceeds your configured latency budget (for example 1,200ms) or returns consecutive HTTP 503 errors, execution automatically shifts to your defined secondary model provider without dropping the active client request.
How is PII handled during vector database lookups?
Our edge proxy passes prompts through a localized named entity recognition pipeline before reaching external model APIs. Sensitive entities such as social security numbers, credit card tokens, and internal email addresses are substituted with cryptographic pseudonyms and reassembled on return.
Does Axiom use our company data to train public foundation models?
Never. Our enterprise agreements explicitly forbid model training on customer payloads. All zero retention configurations ensure that runtime prompts are flushed from memory immediately following execution validation.
How do you guarantee 99.99% uptime for asynchronous agents?
Our control plane operates multi region active active clusters across Northern Virginia and Frankfurt, backed by distributed Raft consensus state machines and automated queue drainage.
